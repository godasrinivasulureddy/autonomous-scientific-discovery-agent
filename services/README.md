# Services
This folder contains the backend services used by the Autonomous Multimodal Scientific Discovery Agent.

## Planned Modules
- gemini_client.py — Gemini API integration
- paper_fetcher.py — ArXiv and PubMed paper retrieval
- pdf_processor.py — PDF text extraction and cleaning
- rag_service.py — Embeddings, vector storage, and similarity search

## Responsibility
Member 1: Gemini LLM/API integration.
Member 2: Paper retrieval and PDF processing.
Member 3: Embeddings and vector database.
