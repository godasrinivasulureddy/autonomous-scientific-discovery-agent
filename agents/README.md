Agent modules for scientific research workflows.

# Agents
This folder contains the AI agents used in the Autonomous Multimodal Scientific Discovery Agent project.

## Planned Agent Modules:
### 1. Literature Reviewer Agent
- Retrieves relevant scientific research.
- Summarizes research papers.
- Identifies research gaps.
- Provides source references.

### 2. Hypothesis Generator Agent
- Analyzes literature findings.
- Generates research hypotheses.
- Explains hypotheses using retrieved evidence.

### 3. Code Executor Agent
- Runs predefined, controlled Python experiments.
- Collects experiment results.
- Reports execution errors.
- Supports bounded retry workflows.

### 4. Statistical Critic Agent
- Evaluates experiment results.
- Checks statistical metrics.
- Identifies limitations.
- Provides feedback on findings.

## Technologies

- Gemini Cloud API
- RAG
- Multi-agent orchestration
